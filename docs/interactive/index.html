Open-source security scanner

Know if your app is secure before you ship it

isitsecure attacks your running site, reads your source code, and has a language model review the risky parts. One scan, one graded report, and patches for what it finds. These pages show how each part works, step by step.

Install and run a scan

Needs Python 3.11+ and git. The installer sets up an isolated environment and runs first-time setup. Nothing here needs an API key; add one to turn on the LLM review.

Install · macOS / Linux
curl -fsSLo install.sh \
  https://raw.githubusercontent.com/jaurakunal/isitsecure/main/install.sh
bash install.sh
Scan a live site
isitsecure scan https://your-app.com --llm none
Scan source code
isitsecure scan --repo ./your-app \
  --mode code-only --llm none
Scan and fix everything
isitsecure fix --repo ./your-app --dry-run

Windows installer, manual install, MCP setup and every flag are in the README.
